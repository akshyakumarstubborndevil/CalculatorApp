# CalculatorApp
Developed a simple Calculator Android App using Android Studio. The application performs basic arithmetic operations such as addition, subtraction, multiplication, and division using user input. This project helped in understanding Android UI components, button click events, and basic logic implementation.


This is a simple Calculator Android App developed using Java and XML in Android Studio.

## Features
* Addition
* Subtraction
* Multiplication
* Division

## Technologies Used

* Android Studio
* Java
* XML

## Description

The app performs basic arithmetic operations using user input. This project was created as Task 1 for the Android Development Internship at SkillCraft Technology.
